# Phone test

**In short:** the last check before handover. Two people, one **iPhone** and one **Android** phone, about 45 minutes. Tick each line on both phones. Anything odd: screenshot it and send it to the developer.

App: https://ri-dev-bloom.github.io/tutorlink/
Test logins (tap **Email and password**): admin@gmail.com, tutor@gmail.com, lecturer@gmail.com, student@gmail.com. The password is shared privately; these accounts are removed at handover.

## 1. Install and notifications (each phone)
- [ ] Open the link. iPhone: **Safari → Share → Add to Home Screen**. Android: **Install app** (or ⋮ → Add to Home screen).
- [ ] Open TutorLink **from the home screen icon** from now on.
- [ ] Sign in as the tutor. Profile → Device → **Notifications** on. Allow when asked.

## 2. Check-in in class (tutor on phone A, student on phone B)
- [ ] Tutor: **Start check-in** → In class, length 1 h, open for 10 min → Start. A QR code shows, with 6 letters underneath, both changing every 15 seconds.
- [ ] Student (phone B): Home → **Check in to a session** → allow the camera → point at the QR. "You're checked in" with the module, tutor and time.
- [ ] Tutor: the student's name appears within a few seconds, labelled **QR**.
- [ ] Student: Home → **My attendance** shows the module line moving.
- [ ] Scan the QR with the phone's **normal camera app** instead: it opens TutorLink and checks in (or says "Already checked in").
- [ ] Tutor: **Show on a laptop** → send the link to yourself on WhatsApp → open it on a laptop. The QR shows full-screen and the count goes up.
- [ ] Tutor: **+ Add by hand** → a made-up student number (ST + 8 digits) and a name → shows as **Manual**.
- [ ] Tutor: **Close check-in**. The laptop screen says "This check-in has closed".
- [ ] Tutor: **Download register (PDF)** → it opens or saves, and looks neat.

## 3. Check-in online
- [ ] Tutor: Start check-in → **Online (Teams)**, open for 5 min. A 4-digit code shows and changes every 30 seconds.
- [ ] Student: Check in → type the code → checked in, labelled **Online**.
- [ ] Wait two minutes, then try an *old* code: it's refused.

## 4. Admin
- [ ] Sign in as admin. Overview: the semester card, To do, Pay this semester, the weekly chart.
- [ ] To do → the tutor's session → **Confirm**. Its pay shows (rate × hours).
- [ ] Overview → **Attendance by module** → a module → Students and Sessions. Download both CSVs; they open in Excel / Google Sheets.
- [ ] Pay this semester → **Pay sheet** → Download pay sheet (CSV).
- [ ] Settings: the groups look right; turn **Auto-decline** on and off; open High-risk modules.

## 5. Lecturer
- [ ] Sign in as the lecturer. Tutors tab shows the test tutor and their next session.
- [ ] **Attendance** tab shows only their modules. Open a session: read-only (no "Add by hand").
- [ ] Message the tutor with a **file attached**. The tutor's phone buzzes; the file opens.

## 6. Student applying
- [ ] Sign in as the student. Profile → **Apply to become a tutor** → tick a module, type a %, add a photo of any document → Send.
- [ ] Admin: Applications → open it → **Open their results document** → it moves to Under review.

## 7. Switching accounts on one phone
- [ ] Sign out, sign in as someone else, turn notifications on. Send that person a message from another phone: it arrives. The previous account's notifications don't.

## Notes for iPhone
- Notifications only work in the app opened **from the home screen** (iOS 16.4 or later).
- If the camera doesn't open: iPhone Settings → TutorLink (or Safari) → Camera → Allow. The 6 letters always work as a backup.
