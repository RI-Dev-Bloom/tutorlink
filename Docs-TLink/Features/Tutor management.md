# Tutor management

**In short:** for each tutor, admin can see and handle their sessions, registers and pay.

## What it does
- Sessions with a **Confirm** button on the pending ones.
- **Weekly slots**: set the tutor's day, start and end time, venue, module and end date. See [[Schedule]].
- **Add session**: a one-off session, confirmed straight away (admin already has the register).
- **Quota**: change this tutor's quota on its own. See [[Session quota]].
- Registers on file.
- What they're owed, and **Mark as paid** (marks every confirmed session as paid).
- Their quota usage.
- A mail icon to message them.

## Why it's here
Confirming and paying is the biggest recurring admin job, and it needs to work while walking between offices.

Related: [[Log a session]], [[Pay]], [[Session quota]]
