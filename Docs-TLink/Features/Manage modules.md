# Manage modules

**In short:** admin can add, rename and merge modules.

## What it does
- Add a module (code and name).
- Fix a name.
- **Merge** two modules (e.g. a student added `prog6221` with a typo). Everything attached to the duplicate moves to the right one.
- Hide modules that no longer run.

## Why it's here
Students can add modules ([[Module picker]]), so someone has to clean up after them.
