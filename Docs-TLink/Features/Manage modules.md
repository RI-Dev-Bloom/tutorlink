# Manage modules

**In short:** the modules and qualifications are Rosebank Bloemfontein's official list (32 qualifications, about 600 modules). Only admin can change it.

## What it does
- **Settings → Modules:** search by code or name, filter by faculty. Add, rename, hide or merge.
- **Settings → Qualifications:** the list students pick from, grouped by faculty. Rename or hide old ones.
- **Settings → High-risk modules:** one switch per module. Only these are open for students to apply to tutor (see [[Apply to tutor]]). Each module shows how many students take it and how many tutors it has, and the most-taken come first. Filter by faculty, or search for any other.
- **Lecturers:** when admin sets a lecturer's modules, they search the list (with a faculty filter) instead of scrolling through every module.

## Why it's here
Students used to add modules themselves. Now the list comes from Rosebank, so everyone uses the same codes and names, and reports by faculty work.

## Rules
- Module codes look like `PROG5121` (3–5 letters, then 3–4 digits).
- Students can't add modules. Admin adds any that are missing.
