# Applications

**In short:** admin reviews every application with the marks and the eligibility flag on one screen.

## What it does
- The list can be filtered by Pending, Under review, Approved and Declined. Search by name or student number.
- The detail screen shows a bar per module coloured by mark, with the applied-for modules tagged and a tick or cross against each.
- A link opens the uploaded results PDF so admin can check the typed marks.
- **Background check → Mark done** moves the application to Under review.

## Why it's here
This is the decision that changes someone's semester. Having everything on one screen means it's made on the marks, not on the name at the top.
