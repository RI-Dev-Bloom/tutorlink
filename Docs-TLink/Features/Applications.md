# Applications

**In short:** admin reviews every application with the marks and the results document on one screen.

## What it does
- The **Applications** tab shows a count of applications waiting. Filters: Open (oldest first, like a queue), Approved, Declined and All. Search by name, student number, email or module code.
- Badges in the queue: **Below 75%** if a mark is under the minimum, and **Auto-declines** if auto-decline is on and none of the marks reach it.
- An application stays **New** until admin opens the results document or marks the results as verified. Then it moves to **Under review**, so the student can see someone is looking at it.
- The detail screen shows a bar per module coloured by mark (green: enough, amber: 50% and up, red: below 50%), with a tick or cross against each.
- If no module reaches the minimum, a note says so, and when auto-decline will decline it.
- **Results verified → Mark done** is needed before approving. It can be undone while the application is still open.

## Why it's here
This is the decision that changes someone's semester. Having everything on one screen means it's made on the marks, not on the name at the top.
