# Applications

**In short:** admin reviews every application with the marks and the eligibility flag on one screen.

## What it does
- The **Applications** tab shows a count of applications waiting. Filters: Open (oldest first, like a queue), Approved, Declined and All. Search by name, student number, email or module code.
- A red **Below 75%** badge appears if a mark no longer meets the minimum (e.g. admin raised it after the student applied).
- Opening a new application moves it to **Under review**, so the student can see someone is looking at it.
- The detail screen shows a bar per module coloured by mark (green: enough, amber: 50% and up, red: below 50%), with the applied-for modules tagged and a tick or cross against each.
- **Open their results document** opens the uploaded PDF or photo so admin can check the typed marks.
- **Background check → Mark done** is needed before approving. It can be undone while the application is still open.

## Why it's here
This is the decision that changes someone's semester. Having everything on one screen means it's made on the marks, not on the name at the top.
