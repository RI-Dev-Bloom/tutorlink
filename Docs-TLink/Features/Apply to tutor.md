# Apply to tutor

**In short:** a student ticks the high-risk modules they'd like to tutor, types their mark for each, uploads their results and sends.

## What it does
Found in **Profile → Tutoring → Apply to become a tutor** (tutors see **Apply for more modules**), with the application's status next to it. The student home screen has a shortcut card too.

1. The form lists only the **high-risk modules**: the ones admin has opened for tutoring in [[Settings]]. Modules they already tutor don't show. If none are open, it says so.
2. Tick a module and a box appears to type the final mark. It says straight away whether the mark meets the minimum (75% by default).
3. Upload the **Academic Statement of Results** (PDF or photo). Big phone photos are shrunk first.
4. Send. The Apply tab then shows a three-step tracker (Submitted, Under review, Decision), what they sent, a link to their document, and admin's reply once it comes.
5. After a decision they can apply again, e.g. for another module. Tutors can do this too.

## Below the minimum
A student can still send a mark below the minimum; the form warns them first. What happens next depends on admin:
- **Auto-decline on:** if none of their marks reach the minimum, the application is declined automatically a day after it's sent, with a polite note explaining why.
- **Auto-decline off:** admin sees it with a **Below 75%** badge and decides.
Approving only ever adds the modules that reach the minimum.

## Rules
- One open application per student at a time.
- Only high-risk modules can be applied for. The database checks this too, not just the app.
- The whole application is saved in one step, so a dropped signal can't leave a half-saved one behind.
- Admin checks the typed marks against the uploaded document.
- Only the student and admin can see the uploaded file.
