# Apply to tutor

**In short:** a student uploads their results, enters their marks and picks the modules they want to tutor.

## What it does
1. Upload the **Academic Statement of Results** (PDF or photo). Big phone photos are shrunk before uploading, so they go up quickly on mobile data.
2. Add each module on it and type the mark.
3. Tap **I want to tutor this** on the ones they'd like to tutor. The button only works when the mark is high enough, and it says so.
4. Send. The Apply tab then shows a three-step tracker (Submitted, Under review, Decision), what they sent, a link to their document, and admin's reply once it comes.
5. After a decision they can start a new application, e.g. to add more modules. Tutors can do this too.

## Why it's here
It's the only way tutors come into the system. It used to be a separate web app. Now it lives in the same app as everything else.

## Rules
- One open application per student at a time.
- Every module they ask to tutor must be at or above the minimum mark (75% by default, set in [[Settings]]). The database checks this too, not just the app.
- The whole application is saved in one step, so a dropped signal can't leave a half-saved one behind.
- The student types in the marks, and admin checks them against the uploaded PDF. We're not reading PDFs automatically, which keeps it simple and free.
- Only the student and admin can see the uploaded file.
