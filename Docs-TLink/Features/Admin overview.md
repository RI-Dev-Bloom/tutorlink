# Admin overview

**In short:** admin's home screen shows what's waiting.

## What it does
Open applications, active tutors, money outstanding, and a warning strip when sessions are waiting to be confirmed. Recent applications are one tap away.

## Why it's here
Admin's job is a queue. The first screen should show what's stuck, not a chart.
