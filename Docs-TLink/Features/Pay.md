# Pay

**In short:** tutors are paid once per semester. Every session admin confirms counts towards the total, and Rosebank pays it all after the semester ends.

## How it works
1. The tutor runs a session and logs it (how many students came).
2. Admin checks it against the signed register and confirms it. That locks in the rate per session.
3. Confirmed sessions add up through the semester.
4. After the semester ends, admin downloads the **pay sheet** and Rosebank pays each tutor their total in one go.

There's no "mark as paid" in the app. The app keeps the count; Rosebank does the paying.

## What the tutor sees (Pay tab)
- **Confirmed so far** this semester, as a big figure.
- A bar showing the three parts: confirmed, waiting for admin to confirm, and still scheduled. Plus what it **could reach** if every scheduled session runs.
- When the semester ends, so they know when the money comes.
- A list of this semester's confirmed sessions, and **Download statement (CSV)**.
- Earlier semesters, one line each with what they earned.

## What admin sees
- **Overview → Pay this semester:** the payout building up across all tutors.
- **Semester pay** (tap that card): one line per tutor with confirmed sessions and amount, a warning if anything still needs confirming, and **Download pay sheet (CSV)** for finance. Earlier semesters can be picked at the top.
- Each tutor's page shows what they've earned this semester.

## Rules
- Only confirmed sessions count. Waiting and scheduled amounts are estimates at today's rate.
- The rate comes from [[Settings]]. Changing it doesn't change sessions already confirmed.
