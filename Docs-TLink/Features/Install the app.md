# Install the app

**In short:** a short guide that helps people add TutorLink to their home screen.

## What it does
- Android (Chrome): shows an **Install** button.
- iPhone (Safari): shows "tap Share, then Add to Home Screen" with a small picture.
- Once installed, it opens full screen like a normal app and can receive notifications.

## Why it's here
We're not in the App Store (that costs money). On iPhone, web notifications **only** work once the app has been added to the home screen. Without this step, iPhone users would never get notified.

## Rules
- Shown once after first sign-in, and again from Profile if they skipped it.
- Never shown again once the app is installed.
